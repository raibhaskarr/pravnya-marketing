# Blog articles

One Markdown file per article: `content/blog/<slug>.md`. The file name is the URL: `/blog/<slug>`.

## Front matter (required unless marked optional)

```
---
title: How to track your child's IEP goals at home
seoTitle: Shorter title for search results  # optional — use when title is over 50 characters
description: 120–155 characters, one full sentence, used in search results.
date: 2026-11-12
topic: Navigating the system   # one of: Understanding your child | Navigating the system | The record | Privacy and data | Ask Pravnya AI
author: The Pravnya team
reviewedBy: Name, qualification   # optional — only if a real professional has reviewed it
---
```

## Body: supported Markdown

- `## Heading` and `### Subheading` (never `#` — the title is the page's H1)
- Paragraphs separated by a blank line
- `- item` bullet lists and `1. item` numbered lists (one line per item)
- `**bold**`, `*italic*`, `[link text](/path)` or `[link text](https://…)`
- `> quote` for a single-paragraph callout

Nothing else (no tables, images, HTML or nested lists).
